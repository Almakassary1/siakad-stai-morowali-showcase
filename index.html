SIAKAD STAI Morowali

Sistem informasi akademik berbasis web untuk Sekolah Tinggi Agama Islam Morowali: dari KRS mahasiswa, penilaian dosen, hingga Command Center pimpinan dengan peringatan dini akademik. Struktur datanya mengikuti kode referensi PDDikti / Neo Feeder sejak awal. A web-based academic information system for STAI Morowali, an Islamic college in Central Sulawesi: student course registration, lecturer grading, and an executive Command Center with an academic early-warning system. The data model follows PDDikti / Neo Feeder reference codes from day one.

KeamananSecurity

Login yang dibuat dengan seriusAuthentication done properly

  • Password di-hash dengan scrypt, perbandingan waktu-konstanscrypt password hashing, constant-time comparison
  • Sesi bertanda tangan HMAC, httpOnly, otomatis gugur saat password digantiHMAC-signed httpOnly session, revoked when the password changes
  • Pembatasan percobaan login dan audit setiap login gagalLogin rate limiting and an audit entry for every failed attempt
  • Hak akses per peran dan per program studiPermissions scoped by role and by study program
